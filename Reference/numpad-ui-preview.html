设计意图 · 约束即版式

为什么长这样

284×76 的横长比例、双色极简与实体键盘属性，决定了每一处布局与交互取舍。

01

长条屏即版式

信息只能纵向压缩：主页 60:40 分栏，计算器全屏只读，设置四行到底。每一像素都被安排，不存在装饰性留白。

02

双模即反向 token

深色不是另一套配色，而是同一组 token 的极性反转：背景↔文字、卡片↔边框、激活态反白。一个标志翻转，全局生效。

03

实体键盘，屏幕只读

设备本身就是小键盘，计算器不再放屏幕按键——屏幕只显示运算过程与结果，不与物理输入打架。

04

三页闭环，减少翻页

待机时钟与键盘模式合并为主页，三个页面三个指示点，左右滑动直达。整机控件 < 100，主题切换全量刷新无压力。

主题切换机制

全局标志 g_theme_dark 翻转 → 调用 ui_theme_apply_all() 遍历控件执行 lv_obj_remove_style_all() 并重新 lv_obj_add_style()。本预览用 CSS 变量模拟同一机制：切换 .dark 类即整页重映射 token，瞬时生效、无闪烁、无残留。屏幕对象总数 < 100，直接全量刷新即可。
