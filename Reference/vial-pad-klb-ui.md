# 克兰因蓝 · CH582 VIAL PAD 界面设计规范

**版本** v1.0 · **目标** CH582 VIAL PAD 固件 · **显示** NV3007（428×142 逻辑横屏 / 142×428 物理竖屏）· **色深** 16bit RGB565

> 配套交互预览：`vial-pad-klb-ui.html`。本文为固件实现参考：
> 坐标为逻辑像素（左上原点），RGB565 为 5-6-5 四舍五入换算，sRGB 为 8bit 参考值。

---

## 1. 设计语言

| 维度 | 规则 |
|---|---|
| 身份色 | 国际克莱因蓝 IKB `#002FA7` |
| 形状 | 直角方框磁贴（radius 0），1px 细框，8px 统一间隙 |
| 字体 | 细字重 200–300；拉丁数值用等宽（tabular）保证对位，中文用系统 Light |
| 主题 | 深色（默认）＝墨蓝地面 + 克莱因蓝磁贴；浅色＝冰白地面 + 白磁贴；激活一律反相 |
| 强调 | 每屏 ≤ 2 处，只给「当前」与光标 |
| 反 AI 味 | 无渐变 / 无圆角卡片 / 无 emoji 图标 / 无多强调色 / 无假数据 |

## 2. 色彩令牌（sRGB → RGB565）

### 2.1 深色主题（默认）

| 令牌 | 用途 | sRGB | RGB565 |
|---|---|---|---|
| bg | 屏幕地面 | `#0A1235` | `0x0886` |
| card | 磁贴底 | `#24326B` | `0x218D` |
| fg | 主文字 / 数值 | `#F2F5FB` | `0xEFBF` |
| muted | 标签 / 次级说明 | `#96ACD1` | `0x9559` |
| active | 激活磁贴 / 光标 | `#99D7FF` | `0x9EBF` |
| active_fg | 反相态文字 | `#070F2C` | `0x0885` |
| brand | 克莱因蓝 IKB | `#002FA7` | `0x0194` |

### 2.2 浅色主题

| 令牌 | 用途 | sRGB | RGB565 |
|---|---|---|---|
| bg | 屏幕地面 | `#F0F4F9` | `0xEF9E` |
| card | 磁贴底 | `#FCFEFF` | `0xFFFF` |
| fg | 主文字 / 数值 | `#1A264B` | `0x1929` |
| muted | 标签 / 次级说明 | `#5D6FA6` | `0x5B74` |
| active | 激活磁贴 / 光标 | `#002FA7` | `0x0194` |
| active_fg | 反相态文字 | `#EEF2F7` | `0xEF9E` |
| brand | 克莱因蓝 IKB | `#002FA7` | `0x0194` |

> 细框 `border` 与软底色 `soft` 为 alpha 叠加，绘制时现算、不单独存 565：
> 深色 = fg 26% over card；浅色 = mid-blue 50% over bg。

### 2.3 令牌用途

`bg` 屏幕底 · `card` 磁贴底 · `border` 1px 细框 · `fg` 数值/标题 · `muted` 标签/次级 · `active` 激活磁贴/光标/状态点 · `active_fg` 激活态文字 · `soft` 悬停/柔背景。

| 角色 | 内容示例 | 字高 | 字重 | 备注 |

## 4. 磁贴与组件

### 4.1 磁贴
- 直角 radius 0；1px 细框（`border`）；底 `card`；内边距 8–10px；间隙 8px；
- 激活态：底 `active` + 文字 `active_fg`（反相）；
- 禁用态：文字与 card 同调（对比度允许降低）。

### 4.2 状态条（head，高 18px）
- 左：品牌 `NV·PAD`（8px，muted）；
- 右：状态点（5×5px，`active`）+ 模式名（如 `BT`）。

### 4.3 芯片 / 进度条 / 开关
- 芯片：1px 细框 + 8px 字；强调芯片反相（`active` 底 + `active_fg` 字）；
- 进度条：3px 高轨道（track）+ 填充（muted）；
- 开关：13×13px 方框，ON = `active` 填充。

### 5.4 CALC-01 计算器 · 结果页
- 右上芯片 `DEC`；
- 右下右对齐：表达式 `1,280 × 3.5 =`（13px，muted）→ 结果 `4,480▍`（40px，fg；光标 `active`，1.1s 闪烁）。

### 5.5 CALC-02 计算器 · 运算页
- 右上强调芯片 `M · 512`；
- 左：历史列表（宽 176：标签 `最近计算` + 3 行 表达式/结果）；
- 右：表达式 `256 ÷ 4▍`（22px）+ 预览 `= 64`（13px，muted）。

## 6. 状态与交互

| 交互 | 规则 |
|---|---|
| 主题切换 | 深色 ↔ 浅色：仅切换地面/文字令牌，磁贴与反相规则不变 |
| 层（VIAL） | FN1 / FN2 / FN3，同步更新主页「模式」磁贴 |
| 连接模式 | USB / BT / RF，同步更新「连接」磁贴与顶部状态点 |
| 光标 | 计算器光标 `active` 色，1.1s 闪烁；减弱动效时停用 |
| 焦点（如适用） | 2px `active` 轮廓，对比 ≥ 3:1 |
